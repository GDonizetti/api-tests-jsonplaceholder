# JSONPlaceholder API Tests

Coleção de testes de API REST desenvolvida no Postman, utilizando a API pública [JSONPlaceholder](https://jsonplaceholder.typicode.com/) como ambiente de testes.

## Endpoints testados

| Método | Endpoint       | Descrição              |
|--------|----------------|------------------------|
| GET    | /posts         | Listar todos os posts  |
| POST   | /posts         | Criar novo post        |
| GET    | /posts/{id}    | Buscar post por ID     |
| PUT    | /posts/{id}    | Atualizar post         |
| DELETE | /posts/{id}    | Remover post           |

## Tecnologias

- [Postman](https://www.postman.com/)
- REST API
- JSON

## Como usar

1. Instale o [Postman](https://www.postman.com/downloads/)
2. Importe o arquivo JSONPlaceholder API Tests.postman_collection.json
3. Execute as requisições individualmente ou rode a collection completa via *Run collection*
